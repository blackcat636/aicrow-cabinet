# Чеклісти тестування

Ця директорія містить ручні QA-чеклісти для smoke, regression та release перевірок.

## Мовна політика
- Коментарі в коді мають бути українською.
- Уся документація в репозиторії має бути українською (узгоджено з `.cursor/rules/core.mdc`).

## Актуальність щодо коду
- Smoke-кроки мають відповідати поточному `middleware`, i18n-роутингу та політиці cookies. Якщо під час перевірки виявлено розходження з реалізацією — оновіть чекліст або виправте код окремим PR, щоб QA-інструкції лишались джерелом правди.

## Структура
- `smoke/` — швидкі перевірки критичних flow після змін.
- `regression/` — ширші крос-функціональні сценарії перевірки.
- `releases/` — списки перевірок перед релізом і після релізу.

## Поточні чеклісти
- `smoke/auth-first-refactor.md` — smoke-чекліст для auth-first рефакторингу.

## Як використовувати
- Після ризикових змін запускайте релевантний smoke-чекліст.
- Тримайте чеклісти сфокусованими й перевикористовуваними; окремий файл на фічу/рефакторинг.
- Якщо чекліст виростає, діліть його за доменами (`auth`, `billing`, `workflow`, `i18n`).
